# Ladybug ChatBot 🐞

A themed AI-powered chatbot that responds in the style of Ladybug from Miraculous Ladybug. Built with vanilla JavaScript and powered by the Google Gemini API.

## Features

- Real-time AI chat responses using Google Gemini API
- Ladybug-themed UI with custom profile images
- Keyboard support (press Enter to send)
- Clean message bubbles with user/bot distinction
- Resizable chat window
- Error handling for failed API responses

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Gemini API

## Getting Started

### Prerequisites
- A Google Gemini API key — get one free at [Google AI Studio](https://aistudio.google.com)

### Setup

1. Clone the repository
   git clone hgit clone https://github.com/AmnaaKhan1/BootCamp-Project.git

2. Open script.js and replace the API key placeholder with your own key
   const API_KEY = 'YOUR_API_KEY_HERE';

3. Open index.html in your browser — no server needed!

## Important

Never commit your real API key to GitHub.
Always replace it with 'YOUR_API_KEY_HERE' before pushing.
